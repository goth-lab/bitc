# REFERENCE.md: Справочник языка BIT-C (Простым языком)

Если вы писали на **Go**, **C** или **TypeScript**, синтаксис **BIT-C** покажется вам родным с первой минуты. Никакой магии: всё, что вы пишете, компилируется в плоские структуры C и однотактовые инструкции процессора.

---

## 1. Типы данных: из чего строятся программы

* **Обычные числа:**
  * `int` — целое число (64 бита) для счетчиков, индексов и оценок сходства.
  * `i32`, `i16`, `u8` — компактные целые числа (32, 16 и 8 бит).
  * `bit` — одиночный бит (`0` или `1`), результат любых сравнений (`>`, `==`).
* **Битовые регистры (`bvec<N>`):**
  * Главный тип языка. Вектор из `N` бит (`bvec<4>`, `bvec<64>`, `bvec<256>`, `bvec<2048>`).
  * Компилятор сам выравнивает их в памяти под SIMD-регистры процессора.
  ```text
  mask: bvec<64> = 0xFF00FF00AA55AA55;
  flag: bit = mask[0]; // Читаем самый правый (нулевой) бит
  mask[3] = 1;         // Записываем единицу в 3-й бит
  ```
* **Массивы и указатели:**
  * `bvec<64>[10]` — статический массив из 10 векторов (лежит на стеке, без `malloc`).
  * `*bvec<64>` — типизированный указатель (`&x` — взять адрес переменной, `*p` — изменить значение по адресу).

## 2. Структуры и методы (Как в Go, но без накладных расходов)

В **BIT-C** данные и логика объединяются через `struct` и привязанные к ним методы `fn (self: *Type)`. На этапе компиляции шаблоны `<In, Out>` разворачиваются в конкретные быстрые C-функции.

```text
// Объявляем шаблон слоя нейросети
struct Layer<InBits, OutBits> {
    weights: bvec<InBits>[OutBits];
    threshold: int;
}

// Привязываем метод к структуре (как в Go)
fn (l: *Layer<InBits, OutBits>) predict(input: bvec<InBits>) -> bvec<OutBits> {
    out: bvec<OutBits> = 0;
    for i in 0..OutBits {
        out[i] = count(match(input, l.weights[i])) > l.threshold;
    }
    return out;
}
```

## 3. Атомарные операции: вся «математика» нейросетей

В языке всего **две встроенные инструкции AI** (интринсики) и стандартные побитовые операторы:

* `match(a, b)` — накладывает два вектора `bvec<N>` и возвращает вектор совпадений (`1` там, где биты одинаковые).
* `count(v)` — мгновенно считает количество единиц в векторе (возвращает `int`).
* **Побитовые операторы:** `&` (И), `|` (ИЛИ), `^` (XOR), `~` (инверсия), `<<` и `>>` (сдвиги). Работают на векторах **любой ширины** (даже на 256 и 2048 бит!).

## 4. Управление потоком и модули

* **Подключение библиотек:** `import "std/learn.bc";`
* **Ветвления:** `if score > 40 { ... } else { ... }`
* **Циклы:**
  ```text
  for i in 0..100 { ... }              // Обычный цикл от 0 до 99
  for x in 0..640 step 4 { ... }       // Цикл с шагом 4
  parallel for n in 0..1024 { ... }    // Автоматическое распараллеливание по ядрам CPU
  ```
* **Системные C-функции:** `extern fn now_ns() -> int;` — объявление внешней функции из C-рантайма.
* **Отладка:** `print value;` — выводит значение в консоль в шестнадцатеричном и десятичном виде.
