# BIT-C: Нейросети на языке программистов, а не математиков

Если при словах *«градиентный спуск»*, *«тензоры»* и *«матричное умножение»* вам хочется закрыть вкладку — **вы пришли по адресу**.

**BIT-C** — это компилируемый язык программирования (транслируется в чистый C с SIMD), созданный для того, чтобы писать сверхбыстрый искусственный интеллект без высшей математики, видеокарт и гигабайтных библиотек. Здесь нейросеть строится из того, что вы и так отлично знаете: **битовых масок, структур и обычных логических операций (`XOR`, `AND`, сдвиги)**.

**Почему BIT-C? (Без GPU и без чисел с плавающей точкой):**

* **Альтернатива дорогим GPU:** Вычисления строятся на широких битовых векторах `bvec<N>` (от 4 до 2048+ бит) и целочисленной арифметике с фиксированной точкой (`Q16.16`), компилируемой в выровненный C-код с SIMD (`POPCNT` / NEON / AVX).
* **От микроконтроллеров до AI-агентов:** Статические арены памяти (`ByteArena`), кольцевые буферы без `malloc` (`RingBuffer`), `zero-copy` представления тензоров (`TensorView`) и примитивы для потоковой обработки данных.
* **Встроенное тестирование из коробки:** Нативный синтаксис `test "описание" { ... }` и команда `./bitc test` для проверки алгоритмов и памяти без внешних фреймворков.

## С чего начать: 5 шагов от нуля до своей нейросети

1. **Прочитайте словарик «на пальцах»:** откройте [`CONCEPTS.md`](CONCEPTS.md). За 3 минуты вы поймете, как работает память нейрона без единого числа с плавающей точкой.
2. **Загляните в шпаргалку синтаксиса:** в [`REFERENCE.md`](REFERENCE.md) всего пара страниц — если вы видели Go или C, вы уже знаете 90% языка.
3. **Запустите первый пример («Узнавание образов»):**
   ```bash
   go build -o bitc .
   ./bitc examples/01_dense_memory.bc
   ```
   Вы увидите, как сеть учится различать сигналы, замеряет скорость в наносекундах и сохраняет свои «мозги» в файл на диске.
4. **Запустите мини-языковую модель («Предсказание слов»):**
   ```bash
   ./bitc examples/02_context_llm.bc
   ```
   60 строк кода без единого `float`, которые запоминают фразу *«Кот сел на...»* и сами дописывают *«...коврик»*.
5. **Загляните в стандартную библиотеку (`std/`):**
   Откройте [`std/learn.bc`](std/learn.bc) и [`std/encode.bc`](std/encode.bc). Вы удивитесь, насколько просто устроено «обучение» под капотом — это всего 6 строчек побитовой логики!

   ### Запуск юнит-тестов стандартной библиотеки
```bash
./bitc test tests/mem_test.bc
./bitc test tests/sys_test.bc
```

## Куда смотреть в проекте (Карта репозитория)

* `examples/` — рабочие программы с подробными комментариями для старта.
* `std/` — стандартная библиотека (`test.bc`, `mem.bc`, `tensor.bc`, `sys.bc`, `encode.bc`, `learn.bc`).
* `tests/` — модульные тесты стандартной библиотеки.
* `specs/` — полная спецификация языка и дорожная карта `stdlib` (`SPECIFICATION.md`, `REFERENCE.md`, `CONCEPTS.md`).
* `lexer.go` -> `ast.go` -> `parser.go` -> `sema.go` -> `codegen.go` -> `main.go` — компилятор BIT-C на чистом Go.

## Что почитать и посмотреть: вход в AI для программистов

Если вы хотите глубже разобраться в том, как устроены нейросети и языковые модели, но не хотите продираться через университетские учебники по матанализу — вот лучшие ресурсы, написанные **программистами для программистов**:

### Книги «на пальцах»
* **«Грокаем глубокое обучение» (Grokking Deep Learning) — Эндрю Траск.** Лучшая книга для старта. Автор объясняет нейросети с нуля на простых примерах без сложной математики, показывая, как программа сама находит закономерности в данных.
* **«Deep Learning for Coders with fastai and PyTorch» — Джереми Ховард.** Практический курс «сверху вниз»: сначала вы запускаете рабочие модели для картинок и текста, а потом постепенно разбираетесь, как они устроены внутри (книга доступна бесплатно в репозитории [fastai/fastbook](https://github.com/fastai/fastbook "fastai fastbook github")).
* **«Грокаем алгоритмы» — Адитья Бхаргава.** Если хочется освежить базовую интуицию алгоритмов, графов и поиска с картинками на каждой странице.

### Видеокурсы, от которых загораются глаза
* **Плейлист «Neural Networks» на канале [3Blue1Brown](https://www.youtube.com/playlist?list=PLZHQObOWTQDNU6R1_67000Dx_ZCJB-3pi "3Blue1Brown Neural Networks playlist")** *(есть русская озвучка)*. Гениальная визуализация: за 4 коротких видео вы буквально глазами увидите, как работают слои, веса и механизм внимания в трансформерах.
* **Курс «Neural Networks: Zero to Hero» от [Андрея Карпатого (Andrej Karpathy)](https://github.com/karpathy/nn-zero-to-hero "Andrej Karpathy nn-zero-to-hero github").** Бывший директор по AI в Tesla в прямом эфире с пустого экрана пишет на Python/C микро-движок нейросети и собственный мини-GPT. Настоящий мастер-класс инженерного мышления.
