# BIT-C — Специализированный компилируемый язык для Edge AI и битовых вычислений

**BIT-C** — лёгкий компилируемый язык программирования (транслируется в оптимизированный C99/C11 с SIMD и OpenMP), созданный как быстрая и энергоэффективная альтернатива тяжёлым фреймворкам, вычислениям на GPU и числам с плавающей точкой (`float`).

## Ключевые принципы

* **100% Integer & Bitwise (Никаких `float` и GPU):** Вся математика опирается на целочисленные типы (`int`, `i32`, `i16`, `i8`, `u8`), фиксированную точку (`Q16.16`) и широкие битовые векторы `bvec<N>` (от `bvec<8>` до `bvec<2048>`).
* **Детерминированная память без `malloc` и GC:** Статические арены (`ByteArena`), кольцевые буферы (`RingBuffer`) и `zero-copy` представления (`TensorView`, `GrayImageView`) позволяют запускать код как на серверах, так и на микроконтроллерах.
* **Встроенное тестирование и диагностика:** Нативный синтаксис `test "..." { ... }`, пакетный запуск `./bitc test tests/` и мгновенная проверка ошибок для IDE `./bitc check`.

## Быстрый старт (3 команды)

```bash
# 1. Сборка компилятора (требуется Go и Clang)
go build -o bitc .

# 2. Прогон всех 12 наборов юнит-тестов стандартной библиотеки
./bitc test tests/

# 3. Запуск прикладных примеров (камера, звук, автономный агент)
./bitc examples/04_edge_vision_guard.bc
./bitc examples/05_edge_audio_wakeword.bc
./bitc examples/06_hybrid_robot_agent.bc
```

## Карта репозитория

* `main.go`, `lexer.go`, `ast.go`, `parser.go`, `sema.go`, `codegen.go` — компилятор BIT-C на чистом Go.
* `std/` — стандартная библиотека (16 модулей без `float` и динамических аллокаций):
  * *Фундамент:* `test.bc`, `sys.bc`, `mem.bc`, `tensor.bc`, `stream.bc`, `io.bc`
  * *Сенсорика и инференс:* `encode.bc`, `vision.bc`, `audio.bc`, `learn.bc`, `post.bc`
  * *Когнитивный слой и агенты:* `flow.bc`, `schema.bc`, `context.bc`, `tools.bc`, `reasoning.bc`
* `tests/` — 12 наборов модульных тестов, покрывающих всю стандартную библиотеку.
* `examples/` — 6 рабочих программ от базовой памяти до умной камеры и робота-агента.
* `docs/` — руководство по языку (`LANGUAGE_GUIDE.md`) и справочник библиотеки (`STDLIB_REFERENCE.md`).
* `specs/` — архитектурные спецификации и концепции (`SPECIFICATION.md`, `REFERENCE.md`, `CONCEPTS.md`).
